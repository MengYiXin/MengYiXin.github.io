Skills 创作方法论：从重复操作到自动化

记录日期：2026-05-05

一、为什么要创建 Skills

1.1 问题背景

日常工作中经常处理重复性的技术工作：

  • 重装 Hermes Agent 环境
  • 配置 Git 代理
  • 部署博客到 GitHub Pages
  • 撰写冷邮件序列

每次遇到相同任务，都要重新回忆步骤、重新配置。这是时间浪费。

1.2 Skills 的价值

Skills 机制让人能够：

  • 一句话触发复杂流程：说”帮我重装 hermes”，Claude 自动完成所有步骤
  • 跨 Session 记忆：上一次配置的偏好，下一次自动应用
  • 团队共享：把经验固化成可复用的工具
