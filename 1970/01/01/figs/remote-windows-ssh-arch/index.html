Remote Windows SSH Architecture

Remote Windows SSH: Full Connection Architecture

WSL/本地Linux → 局域网 → Windows OpenSSH Server → 远程命令执行

本机操作 (WSL/Linux)

  • • sshpass + ssh 远程连接
  • • scp 推送脚本/压缩包
  • • git clone 获取 Hermes 源码
  • • tar -czf 打包传输文件

Windows 远程操作

  • • 停止安全服务 (EasiUpdate3Protect)
  • • 查找/安装 Python 环境
  • • pip install setuptools + hermes
  • • 配置环境变量 / API Key

关键经验

  • • 中文编码问题：脚本不穿墙
  • • 网络慢：本地打包再传
  • • NTFS 权限：icacls 开权限
  • • 凭证缓存：查 auth.json
