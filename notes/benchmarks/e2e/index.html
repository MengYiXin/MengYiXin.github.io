端到端延迟 (E2E)

E2E = End-to-End，从请求发起到完整响应结束的总耗时。 单并发场景下，E2E ≈ TTFT + 输出 token 数 × TPOT。

说明

  • 910B4 跑 Qwen3-32B / 30B-A3B (p=2k, o=2k, c=25)，E2E ≈ 4s，对应 TPS 340。
  • 910C 双机 V4-Pro 1M 上下文，E2E 长达 798 小时——这是 Prefix Cache 失效场景的极端值，1M 上下文当前无法走生产。
