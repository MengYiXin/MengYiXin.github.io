四大评估任务

每个任务类型下，相同的 prompt 在不同 (芯片, 模型) 组合上的输出对比。

💬

知识问答

qa

中文领域问答，验证模型的知识储备与中文表达。

示例 Prompt
  • 请用三句话介绍昇腾 910C 相比 910B 的核心升级点。
  • 华鲲振宇在国产算力服务器市场的定位是什么？
🧠

逻辑推理

reasoning

数学 / 代码 / 常识推理，测试 TTFT 与首段响应速度。

示例 Prompt
  • 9.11 和 9.9 哪个大？请详细说明推理过程。
  • 一个水池有两个进水管 A、B 和一个排水管 C……
⌨️

代码生成

code

Python / SQL / Bash 场景，测试长上下文与格式遵循。

示例 Prompt
  • 写一个 Python 函数，输入一组 token 时间戳，输出 tokens/s 实时吞吐。
  • 用 SQL 查每个用户最近 30 天的累计订单金额。
📄

长上下文

longctx

1M 上下文摘要 / 问答，测试 Prefix Cache 命中与端到端延迟。

示例 Prompt
  • 对以下 1M token 合同做摘要并列出所有违约条款……
  • 跨 100 章节长篇小说，归纳主要人物关系图……

📥 如何补全本页
  1. 选定一个 (芯片, 模型, 量化) 组合，准备好 4 个任务类型的 prompt 各 1-2 个
  2. 在硬件上跑出响应，记录 TTFT / TPOT / 吞吐 / 时间戳
  3. 把响应原文复制到对应 demos.yaml（待建）的对应槽位
  4. git push，CI 自动部署，/demos 页立即更新
