昇腾 910C / 910C

新一代 8 卡旗舰推理服务器，单卡 128GB HBM + 互联带宽 780GB/s， FP16 算力 ≥560 TFLOPS/卡。是 V4 Flash / V4 Pro / GLM5 等 主流模型的推荐部署平台。

1. 概述

  • 定位：新一代 8 卡旗舰推理服务器，是 V4 Flash / V4 Pro / GLM5 等主流模型的推荐部署平台
  • 别名：910C / 800I A3 / 800I A3 560T / HuaKun AT958 B3（HuaKun AT958 B3 是同配产品）
  • 厂商：华为
  • 内存：单卡 128GB HBM3
  • 算力：FP16 560 TFLOPS · INT8 1120 TOPS（单卡）
  • 互联：HCCS / RoCE 780 GB/s 8 卡全互联 + 8×400GE RoCE
  • 软件栈：openEuler 22.03 · CANN 8.0.RC2 · MindIE 2.0.RC2 · vLLM-Ascend (deepseekv4-a3) / MindIE / MindSpore
  • vLLM 镜像：quay.io/ascend/vllm-ascend:deepseekv4-a3（参考 []）

7. 灵衢互联架构 (910C)

910C 是首款搭载 灵衢 (UB) 1.0 互联总线的昇腾芯片,8 卡 Mesh 全互联,互联带宽 784 GB/s,较 910B4 HCCS (392 GB/s) 提升 2 倍。
