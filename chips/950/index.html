昇腾 950 (950PR / 950DT)

910C 的下一代旗舰芯片,分为两个型号: 950PR(2026 Q1,推理导向)、950DT(2026 Q4,训推一体)。最大亮点是从 HCCS 升级到自研 灵衢 (UB) 互联,支持超节点 Mesh 全互联,显存带宽最高提升至 9.6 TB/s。

4. 灵衢 (UB) 互联架构

灵衢是华为面向超节点的统一互联协议,1 个协议支持 7 大类计算组件 (CPU / NPU / GPU / MEM / SSU / DPU / Switch),无额外软件开销。

代际互联协议互联带宽互联架构
