使用效果 · DeepSeek-V4-Pro 部署实测

本页记录 DeepSeek-V4-Pro (W4A8 MTP) 在 910B4 / 910C 上的实际部署流程与实测数据。命令均来自 vllm-ascend 官方文档 (quay.io/ascend/vllm-ascend:deepseekv4 / -a3)，可作为客户现场部署的标准参考。

1. 硬件需求

  • 最小部署: 2 台 Atlas 800I A3 (128G × 8) 或 4 台 Atlas 800I A2 (64G × 8)
  • 推荐部署: 4 台以上 (PD 分离可扩展到 8+ 机)
  • 系统盘 / 数据盘: 模型权重 ≈ 700 GB (W4A8), 需 NVMe RAID
  • 网络: RoCEv2 / HCCS 全互联

2. Docker 启动

在每台机器上运行：

A2 系列 (910B4)

# A2 系列 (Atlas 800I A2 = 910B4)
export IMAGE=quay.io/ascend/vllm-ascend:deepseekv4
export NAME=vllm-ascend
docker run --rm \
  --name $NAME \
  --net=host \
  --shm-size=512g \
  --device /dev/davinci0 --device /dev/davinci1 --device /dev/davinci2 --device /dev/davinci3 \
  --device /dev/davinci4 --device /dev/davinci5 --device /dev/davinci6 --device /dev/davinci7 \
  --device /dev/davinci_manager --device /dev/devmm_svm --device /dev/hisi_hdc \
  -v /usr/local/dcmi:/usr/local/dcmi \
  -v /usr/local/Ascend/driver:/usr/local/Ascend/driver \
  -v /etc/ascend_install.info:/etc/ascend_install.info \
  -v /etc/hccn.conf:/etc/hccn.conf \
  -v /mnt/sfs_turbo/.cache:/root/.cache \
  -it $IMAGE bash

A3 系列 (910C)

# A3 系列 (Atlas 800I A3 = 910C)
export IMAGE=quay.io/ascend/vllm-ascend:deepseekv4-a3
# 同上，但 --device 列到 davinci15 (16 卡)

3. 关键环境变量

# 关键环境变量
export HCCL_IF_IP=$local_ip
export HCCL_BUFFSIZE=1024
export ASCEND_RT_VISIBLE_DEVICES=0,1,2,3,4,5,6,7
export OMP_PROC_BIND=false
export OMP_NUM_THREADS=10
export PYTORCH_NPU_ALLOC_CONF=expandable_segments:True
export ACL_OP_INIT_MODE=1
export VLLM_ENGINE_READY_TIMEOUT_S=3600
export HCCL_OP_EXPANSION_MODE=AIV
export USE_MULTI_BLOCK_POOL=1
export USE_MULTI_GROUPS_KV_CACHE=1
export TASK_QUEUE_ENABLE=1
export VLLM_ASCEND_ENABLE_FLASHCOMM1=1
sysctl -w vm.swappiness=0
sysctl -w kernel.numa_balancing=0

4. vLLM serve 启动 (Node0)

# vllm serve 启动 (A2 系列, Node0)
vllm serve /root/.cache/modelscope/hub/models/vllm-ascend/DeepSeek-V4-Pro-w4a8-mtp \
  --host 0.0.0.0 --port 10010 \
  --max_model_len 133072 \
  --max-num-batched-tokens 4096 \
  --served-model-name dsv4 \
  --gpu-memory-utilization 0.9 \
  --max-num-seqs 4 \
  --data-parallel-size 4 \
  --tensor-parallel-size 8 \
  --enable-expert-parallel \
  --quantization ascend \
  --enable-chunked-prefill \
  --enable-prefix-caching \
  --tokenizer-mode deepseek_v4 \
  --tool-call-parser deepseek_v4 \
  --reasoning-parser deepseek_v4 \
  --async-scheduling
