首 token 延迟 (TTFT)

TTFT = Time To First Token，又称首包延迟，是衡量"模型收到请求到返回第一个字"的延迟。 你之前口语里说的"手套延迟"，就是它——本档案统一写 TTFT。

全部 TTFT 数据

关键观察

  • 910C 32 卡大 EP 在低并发 (c=1) 下 V4-Flash TTFT 极低（15ms），适合对延迟极敏感的场景。
  • 910B 单机 跑 V4-Flash 2k/2k，TTFT 约 2.1s，是中小规模延迟敏感场景的性价比之选。
  • 910C 双机 跑 V4-Pro 1M 上下文时 TTFT 高达 666s（Prefix Cache 不命中），说明长上下文 + Prefix Cache 失效是最痛的痛点。
