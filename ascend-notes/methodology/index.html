方法论 · 术语表

本档案对术语、测试方法、数据可信度的统一说明。

测试方法

  • 基线来源：所有数据来自华鲲振宇、华为、vLLM Ascend 官方提供的实测报告或公开基线表。
  • 硬件环境：具体服务器型号 / 卡数 / 互联方式见各芯片页 §2 硬件规格。
  • 软件栈：当前默认 CANN 8.0.RC2 + MindIE 2.0.RC2 + vLLM-Ascend (deepseekv4 / deepseekv4-a3)。
  • prompt / output：每条数据点都标注 p/o 长度，并发数，参见数据表的"配置"列。
  • 状态分级：
    • 已验证 — 多方资料交叉验证
    • 部分验证 — 仅单一来源或单次测试
    • 不支持 — 经测试硬件/软件不支持
    • 未测 — 暂未覆盖

术语表

术语 别名 / 口语 定义
TTFT 首 token 延迟 / 首包延迟 / 手套延迟 Time To First Token，从请求发起到返回第一个 token 的耗时。
TPOT 非首 token 延迟 / 单 token 生成时间 Time Per Output Token，第 2~N 个 token 的平均生成时间。
E2E 端到端延迟 End-to-End，从请求发起到完整响应结束的总耗时。
并发 Concurrency 同时处理的请求数。
吞吐 Throughput 单位时间内生成的 token 总数。
W8A8 权重量化 8bit，激活量化 8bit 权重和激活均做 INT8 量化，精度损失小。
W4A8 / W4A16 权重量化 4bit 权重做 INT4，激活保持 INT8/FP16。模型体积显著缩小。
CANN 昇腾异构计算架构 Huawei Compute Architecture for Neural Networks，昇腾的底层加速库。
MindIE 昇腾推理引擎 Huawei Mind Inference Engine，昇腾官方推理引擎。
HCCS 昇腾片间互联 Huawei Cache Coherent System，910 系列的卡间互联。
RoCE RDMA over Converged Ethernet 在以太网上跑 RDMA，用于跨节点 NPU 互联。
